# 席替えくじ

名簿の番号、名前、性別を読み、教室の席をランダムに決めます。指定した人は、指定した席の中だけで抽選します。

## 使い方

1. 名簿の Excel（.xlsx）か CSV をドロップし、番号、名前、性別の列を確認して取り込みます。性別はなくても引きます。
2. 行と列、座席数、行ごと、または左からの列ごとの席数を決めます。短い行は黒板の中央に揃います。
3. 動かさない人は固定席、一部の席だけで引きたい人は限定抽選にします。
4. 「席替えする」で演出のあと席が決まります。「周りが異性だけにならない」にチェックすると、上下左右が異性だけになる席を避けます。
5. 「掲示用を開く」「教員用を開く」で、結果をブラウザのページとして開きます。印刷して貼れます。

このアプリはブラウザで開いて使います。公開ページは https://lunaneco.github.io/sekigae-kuji/ です。

掲示用のページは、黒板を前の中央に置いた貼り出し用です。向かって左が左です。  
教員用のページは、黒板を前の中央に置いたまま左右を逆にし、一覧も表示します。教卓から見て左が左です。一覧は番号、名前、性別の順です。掲示の座席表には性別を書かず、女子の席だけ文字のうしろに薄い網掛けをします。  
同じ内容は Excel でも保存できます。座席表はA4横1枚、教員用の一覧はA4縦におさまります。

## 名簿の扱い

名簿も結果も、開いているブラウザの中だけに残ります。サーバーへは送りません。

公開ページはアプリ本体だけです。児童生徒の名簿はリポジトリに含まれていません。

## 補足

Excel のセルは数式ではなく文字列として書き出します。読み込むファイルは 5MB、3000行、40列までです。

名簿の読み込みには SheetJS Community Edition 0.20.3（Apache License 2.0、Copyright SheetJS）を同梱しています。結果の Excel はアプリ自身が書き出します。
